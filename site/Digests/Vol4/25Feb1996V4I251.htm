Sorry if this is a repost for you. I has trouble psoting this to

February 23, 1996
From: Dr. Hal Frey, Ken Achiron, Jim Leo, Brian Richmond, Paul
Tickenoff (NGJA - JO Tech Comm)

Please make note of the following information, some of which was not
widely circulated previously and is in effect currently.

1. The following change on Pommel Horse was approved by the JOPC at
the May Nationals in Oakland Ca:

In Class 3 Pommel Horse, the Stockli B required skill has been
changed to: "Any 3 hand-placement skill on 1 pommel (the same
pommel), of B or greater value, performed behind the back." Examples
of some skills that satisfy this requirement are: 2 pommel loops,
Stockli B, Bailie, 3/4 Bailie, or pommel circle. A Russian on 1 pommel
does not satisfy this requirement since it is performed in front of
the body.

Additional clarifications:

1. There is a general requirement in optional pommel horse that all 3
parts of the horse must be worked. Failure to satisfy this requirement
results in a 0.2 deduction from execution. To satisfy this
requirement, at least 1 whole part of "A" value must be performed on
that part of the horse.

General

1. In Class 3 and Class 4 competition, an exercise that is short parts
will incur a 0.8 deduction from execution for each missing value part.
This is not the case for Class 1 or Class 2 competition. Missing value
parts in Class 1 and Class2 will result in a deduction in "difficulty"
as per FIG. There is no deduction in execution for missing value parts
in Class 1 or Class 2.

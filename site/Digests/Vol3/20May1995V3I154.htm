Subject: BB Bonus

As promised :)

1)  2 or more gymnastic elements or two or more gymnastic/acrobatic elements

A+D, B+C = 0.1
B+D, C+C, C+B+C = 0.2 (except consecutive switch-leg leaps = 0.1)
C+C+C and more difficult = 0.3

2)  2 or more:
-- free aerial walkover or cartwheel
-- forward or sideward acrobatic element with hand support
-- forward or sideward salto

A (without flight) + C, B+C = 0.1
A (without flight) + D, B+D, C+C and more difficult = 0.2
C+C+C, B+C+D = 0.3

3) 2 or more acrobatic elements with
-- directional change in one element, or
-- counter element execution

B+C = 0.1
C+C, B+D and more difficult = 0.2


4)  3 or more acrobatic flight elements

B+B+C, B+C+C = 0.1 (except ff-ff-layout step-out)
B+B+C+C, B+B+D, C+C+C and more difficult = 0.2
B+B+C+D and more difficult = 0.3

:)
